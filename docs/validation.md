## 执行方式

两个未继承主对话的执行 Agent，分别读取 Skill 与必要参考，用三个虚构输入完成写作。材料案例同时读取安装版 mathink。禁止联网与补入外部参数。主 Agent 阅读实际输出，核对计算、关键限制与决策状态。

这属于有限任务试用，不是行业基准、真实投资人盲评或对所有模型的保证。公开样本没有被当作当前投资事实使用。

## 试用后修订

首版短汇报机械补入了“未提供负责人姓名”，对本次口头更新没有决策价值。已在文体参考中明确：只保留影响判断或动作的缺口，编辑过程和交付状态放在口头稿之外。随后重读更新后的 Skill 并重写，结果已删除多余说明，正文低于220字限制。

## 语言习惯修订与专项试用

根据用户进一步要求，将自然的机构说话习惯放到入口优先位置。补充直接表达判断、用客户与经营细节说话、必要处才交代保留意见等正面示范；减少虚设反面的刻意对照、抽象术语、逐段套用论证项目及重复总结。财务经营和材料测试中影响结论的名词保留。

独立执行 Agent 读取修订后 Skill，改写三个带有AI套话的虚构段落。主 Agent 核查结果：未出现原稿中刻意的“不是X而是Y”对照；闭环、映射等包装词被展开为交付、回款和成本等具体内容；420万元订单、150万元预付款、审计与管理层预测、交付延期及材料测试条件均保留。没有把订单写成盈利，也未用跨条件测试数据排名。

查看 [专项输入](../examples/fixtures/voice-input.md) 与 [专项结果](../examples/fixtures/voice-output.md)。这项试用检查可观察的编辑行为和事实保留，不使用AI检测器，也不把结果称为真实投资人的文风认证。

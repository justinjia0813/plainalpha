# 中文声音与用语

目标是让文字像一位熟悉业务的投资人所写，读者能听出他的判断、理由和疑虑。中文示范是针对中文投研场景的编辑设计；全部例句为自拟，未冒充机构原话。

## 从已有样本学习什么

Bessemer历史项目备忘录适合学习具体、坦率的项目讨论：先说想做什么，再用客户和经营细节说明理由，没弄清的事直说。Oaktree客户备忘录适合学习从容的解释和有分寸的个人判断。a16z行业文章适合学习把复杂业务讲清楚。各篇原文的范围与局限见 [样本拆解](sample-analysis.md)。

将这些特点转成自然中文。英文原文的夸张比喻、宣传口号和长句不必逐项仿写。用户指定某篇作语言参照时，以该篇和目标读者为准，不混成几家机构的统一腔调。

## 声音要有具体内容

- **有主见。** 直接写“目前最值得继续看的，是……”“公司的优势在……”“我们还拿不准……”，后面接理由。无需每段都用“我们认为”。
- **说业务。** 多写客户怎么买、产品如何交付、价格怎样变化、公司靠什么赚钱。少用抽象名词替代这些关系。
- **有分寸。** 确定的事实直接说。缺什么说清一次，并解释它为什么影响判断；不在每段结尾重复免责声明。
- **解释得从容。** 一段讲清一个主要意思，句长服从内容。可以用一个较长的句子解释取舍，再用短句下判断。
- **有所取舍。** 重要部分写透，常识和次要背景略写。按内容决定段落、列表和表格，避免每段相同长度、相同开头和相同收尾。

“我们”可以表示作者已有判断，不能暗示某投资机构、投委会或团队已经认可。没有材料支持时，不写“据我们多年跟踪”“经过充分尽调”等经历。

## 删去没有信息的强调

默认改掉这些表达形状，直接写具体意思：

| 常见写法 | 编辑动作 |
| --- | --- |
| “不是X，而是Y”“不只是X，更是Y” | 保留有信息的判断，删除为强调而虚设的反面 |
| “真正的关键在于”“本质上”“归根到底” | 直接写关键事实或因果；确有必要重定义概念时给具体解释 |
| “值得注意的是”“需要强调的是”“不难发现” | 通常删去，让后面的事实承担分量 |
| “这才是核心”“这就是价值所在” | 已经讲清时结束段落；还有新后果就直接写后果 |
| 连续“首先、其次、最后”，或强行凑成三点 | 按真实关系衔接；并列事项有几项就写几项 |
| 每段都加“仍需验证”“不能据此判断” | 将同一限制集中到相关判断处，其余段落继续讲业务 |

有实际内容的对照应保留。例如销量增加而价格下降，两项变化都会影响收入；写清各自作用即可。原稿把商机写成订单时，应明确纠正事实。检查对象是多余修辞，不能借此删去不利信息。

## 术语只承担必要的意思

先判断词语是否指向准确、必要的概念。已有清楚的日常说法时，优先使用它。下表按语境取舍，不作逐词替换：

| 容易堆叠的说法 | 可以更直接地说 |
| --- | --- |
| 商业化兑现、需求释放、订单转化闭环 | 客户是否下单，能否按时交货、确认收入和收回货款 |
| 价值捕获、利润留存机制 | 公司能留下多少利润，客户和上游各拿走多少 |
| 证据颗粒度不足、客户验证链尚未闭合 | 还缺连续采购、验收或回款记录；按实际缺项写 |
| 产能爬坡约束与盈利弹性映射 | 新线多久能稳定生产，销量和成本会怎样变化 |
| 建立证伪触发器、形成研究闭环 | 出现什么情况就需要改变判断，接下来查什么 |
| 赋能、抓手、底层逻辑、范式跃迁 | 具体改善了谁的什么工作，成本或效果怎样变化 |

毛利率、现金流、产能利用率等有明确含义的财务经营词可以直接使用。材料名称、测试工况、良率等决定结论的技术信息也应保留。给非技术合伙人的报告先说明业务影响；详细参数放表格或技术附录。不能把不同测试条件、采购单耗和净材料用量混写成一个词。

## 保留事实和判断的分寸

| 内容 | 自然表达示例 |
| --- | --- |
| 确定事实 | “2025年目标产品收入为……” |
| 主体自述 | “公司披露……”“管理层预计……” |
| 数据推算 | “按上述用量和价格计算……” |
| 作者判断 | “我们看好这一方向，原因是……” |
| 条件预测 | “如果客户继续增加采购，收入有望……；目前还缺……” |
| 未知事项 | “我们还不知道客户能否持续采购，这会影响……” |
| 来源冲突 | “两份材料的估值不同，最终条款还没有确认。” |

“领先”应交代比较对象和指标，“壁垒”应说明竞争者为何难以跟上，“放量”应有持续交付或采购依据。说“安全边际”需要估值、交易条件和下行情景。没有这些内容时，直接说现阶段已经知道什么、还不能决定什么。

## 段落示范

下面的改写保留各例给定的信息，不新增行业事实。

### 1. 直接说明下一步

原稿：

> 我们要关注的不是单点技术突破，而是商业化兑现的底层逻辑。真正的关键，在于能否构建客户验证闭环。

改写：

> 接下来要看客户会不会继续下单。技术测试之后，产品还要经得起持续生产和实际使用，公司的销售计划才有依据。

### 2. 说明一家公司的进展

给定事实：公司披露两家客户通过指定测试，其中一家发生一次复购；没有连续交付、价格或成本资料。

原稿：

> 公司已构建高壁垒客户认证体系，商业化兑现确定性持续提升。

改写：

> 公司披露已通过两家客户的指定测试，其中一家有过一次复购。客户导入已有进展，接下来要看能否稳定交货，以及这些订单能给公司带来多少利润。

### 3. 解释增长中的取舍

给定分析：设备数量增加，每台采购材料用量减少，材料价格也下降；无供应商成本数据。

原稿：

> 终端高景气并不等于供应商利润弹性的线性映射，需建立量价利穿透分析框架。

改写：

> 设备卖得更多，每台用的材料却在减少，材料价格也在下降。供应商最终能赚多少，还要看销量能否补上这部分影响，以及成本降得有多快。

### 4. 自然地表达暂缓判断

给定事实：有试购，缺复购和回款记录；交易价格未确认。

改写：

> 客户试购说明产品有初步需求。我们还想看到几批后续订单和实际回款，再判断这门生意能做多大。交易价格也没有确认，现在作投资决定还早。

## 最后一遍编辑

把稿件当作给同事读的文字通读一遍。删掉提醒读者注意却没有信息的开头，合并重复结论，展开空泛术语。检查有无刻意对照、整齐排比、装饰性加粗和机械总结。

再核对一次数字、日期、主体、范围和条件。文字可以更短，业务信息和必要的技术含义要准确。无需用AI检测器给文章打分，也不声称文字已无法被识别为AI生成。

# 论证与编辑规则

## 一个段落完成一个主要判断

在内部检查全文的重要判断是否有依据、解释和适用条件。段落按内容自然展开，客户故事、事实说明和直接判断都可以独立成段，无需每段装入同样的项目。

判断要回答读者的问题。数据和事实让他知道理由，必要的解释帮助他看清客户、经营或投资会受什么影响。条件在会改变意思的位置说清，同一限制不反复提醒。

不是所有段落都需要得出投资结论。技术定义、口径说明和数据表注释应完成其自身任务。

## 六种关键论证

| 论证对象 | 必须补足的连接 | 常见跃迁及修正 |
| --- | --- | --- |
| 行业增长 | 终端变化—采购量/单耗/采用率/价格—可实现收入 | 行业繁荣不能直接推出某家公司获利；补供给、份额和成本约束。 |
| 技术优势 | 同条件表现—客户门槛—制造与采用—经济收益 | 实验室结果只能支持已测试范围；补量产和客户验证。 |
| 竞争壁垒 | 能力差异—复制代价—客户选择—收益留存 | 把专利数量、认证或历史份额当作线索，检查实际复制与议价条件。 |
| 公司成长 | 客户需求—采用—交付—收入—利润与回款 | 意向、测试、订单、确认收入和现金流分别表述。 |
| 交易回报 | 进入价格—经营结果—稀释/资本需求—退出/分配—期限 | 有前景不能直接推出价格合理；缺项则保留回报判断。 |
| 风险 | 事件条件—传导路径—财务或经营后果—观察信号 | 用具体暴露代替“政策/技术/市场风险”空标签。 |

## 事实、估算、判断和预测

来源只能证明其能观察的内容。公司自述可以作为分析输入，但不能因句子被润色而变成独立验证。引用编号及定位跟随相应主张移动。

已有估算保留输入、单位、公式和条件。新增计算只在任务授权且资料足够时做，并标“据所给数据计算”。没有真实概率依据时，使用条件情景。

数字相同但时间、地域、产品层级不同，不能合并。样本中的共同特征不能无条件外推全行业。

## 处理反对理由

找到会实质改变当前判断的反对理由，说明它影响哪个假设。可以有证据地反驳、限制结论或保留开放问题，不要求每段机械配反方。

编辑不得为了叙事完整而删除关键反证。尤其保留客户流失、毛利承压、现金不足、供给过剩、验证未完成和交易不确定性。优点与缺点是否重要，由其影响判断，而非要求正反篇幅对称。

## 把研究含义写成可执行动作

“值得关注”应说明关注对象、理由、需要验证的信息及可能改变的判断。例如“核对A客户下一批采购及退货记录，以判断一次验收能否转为持续供货”。

动作与证据状态匹配。研究优先级、进入尽调、商务谈判、投资审批和已批准投资分别表述。授权与审批状态只能来自真实材料。

## 表格与标题

标题不能比正文更确定。原文只有送样，标题就不能写“国产替代开始兑现”。并列比较统一口径；无法统一时在单元格旁写出差异。

来源和重要限制靠近对应结论；详细台账与计算放附录。避免把所有限定移到页尾，导致摘要失真。

## 编辑后的核对表

| 项目 | 检查什么 |
| --- | --- |
| 数字 | 金额、数量、单位、币种、区间、百分比与百分点保持一致 |
| 范围 | 地域、品级、样本、客户、期间及交易层级未扩大 |
| 归属 | 管理层、客户、研究团队的发言和判断仍能区分 |
| 状态 | 实际/目标、测试/量产、意向/订单、收入/回款、提案/批准未混淆 |
| 强度 | 相关/因果、可能/预计/确定、证据缺失/证据否定未混淆 |
| 连贯 | 摘要、标题、表格、正文和图注表达同一结论 |
| 决策 | 有收益主张时有必要条件，重要反证与未知未被隐藏 |

硬错误先修正；语言偏好再优化。不得为了分数或风格偏好修改事实。检查结果可记录“通过/需修订/资料不足”，不伪造机构审阅或真实投资人评分。

# 文体结构

按任务读对应部分。用户的机构模板、篇幅与读者要求优先。本文件给编辑判断，不要求所有报告套同一目录。

## 行业研究：围绕决定价值分配的变化

首页先回答：研究边界是什么；主要变化是什么；哪些证据支持；瓶颈与收益可能留在哪里；最可能改变判断的未知是什么。

正文按研究框架展开。与 mathink 配合时，八章分别承担以下表达任务：

| 章节 | 对投资读者说明的含义 |
| --- | --- |
| 材料解决的问题 | 客户为何需要付费，何时无需升级 |
| 技术路线 | 哪些方案在何种约束下会被选择 |
| 市场规模 | 当前成交或采购规模与未来条件需求分别有多大 |
| 需求驱动 | 哪项变化进入用量、采用率或价格，什么因素抵消它 |
| 产业链与商业模式 | 谁承担投入和风险，谁能留下利润与现金 |
| 技术壁垒 | 哪项能力难复制，优势是否能被供应商获得 |
| 竞争与国产化 | 同级竞争者和有效供给到了哪一步，份额口径是什么 |
| 未来变化 | 技术、产品、竞争、风险的条件与观察信号 |

一章内以关键判断开头，再放必要证据与解释。无需每章机械写投资建议。表格用于同口径比较；图表标题应与数据所能支持的判断一致。

## 项目投决建议：围绕决策与承诺

若已有内部 IC 模板，保留它。若没有，可采用下面的决策顺序，按项目合并章节：

1. **请求事项与当前建议**：讨论、继续尽调、附条件推进或提交投资审批；金额、工具、估值、股权及条件按已有材料写明。提案和批准结果分开。
2. **投资理由**：为什么这项机会值得承担风险；为什么选择这家公司；为什么是现在。按证据选择最关键的理由。
3. **经营机制与验证**：客户问题、产品采用、交付、获客、单位经济及现金约束。规模、效率与质量同时看。
4. **竞争与可持续性**：优势是什么，替代、客户自制、新供给或议价如何削弱它。
5. **交易与收益路径**：已有条款、经营结果、退出或分配路径、稀释、期限与下行情景。模型不足时列缺口，不补造倍数、概率或目标收益。
6. **主要反对理由与应对**：写出最强反方，它会怎样影响收入、利润、现金或退出，以及剩余风险由谁承担。
7. **决策条件与后续工作**：什么证据会支持扩大承诺、什么会导致暂缓或终止。负责人和日期仅在已知或用户要求安排时填写。

交易条件只给一部分时，标题写“投资讨论稿”或“待补充条件的建议稿”。保留用户要求的文体，同时明确完成范围。无估值与回报依据时，可表达继续研究的建议，不能凭文风推出“具备充足安全边际”。

历史投资 memo 常保留不确定性，并让它改变当前承诺。迁移到新任务时，根据证据讨论合理动作；不机械复制小额试投、分期投资或某机构条款。

## 更新：以基准判断变化

围绕“上期判断/计划—本期事实—差异原因—影响—动作”展开。先说明决策相关变化，后补常规指标。

- 数据超预期：核对基准及可比口径，区分提前确认、价格、数量、一次性与持续因素。
- 数据低于计划：说明影响哪个原假设，是否改变资金、交付或竞争判断。
- 判断维持：列本期新增支持与仍未解决的反对理由。
- 观点改变：指出哪项新证据改变哪项假设，避免用新结论覆盖旧口径而不解释。

不把访问、开会、送样等活动数量当成结果，除非活动本身就是所跟踪的里程碑。

## 简报与口头汇报

按“当前判断—最有力的依据—最大限制—下一步”组织。口头表达用完整句，减少长括号、密集缩写与表格依赖。书面简报可用少量并列项目。

长度越短，越要保留改变意思的限制。例如“公司预计”不能压缩成事实，“两个测试客户”不能压缩成“头部客户已放量”。不要求列出所有背景。

口头稿只保留影响判断或动作的内容。任务没有要求安排负责人时，不机械补上“未提供负责人姓名”。编辑检查、资料处理说明与交付状态放在稿件之外。

## 决定篇幅

把篇幅分配给对结论最敏感、争议最大或证据最薄弱的部分。背景定义只写理解机制所需的内容。证据多但重要性低的资料放附录。正文可通过来源编号回到页码、表或模型，不展示内部逐步思考记录。
